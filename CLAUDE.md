# Project Data Analytics — Session Start Instructions

**Before responding to anything else in a new session here:**

1. Identify the machine (`hostname`) and whether this is the **Claude
   Desktop app** or a **terminal `claude` CLI** session. Don't guess this
   from which tools are available — that's unreliable (both surfaces can
   expose similar tools, confirmed by this actually going wrong once).
   Instead check your own system prompt/environment section for an
   explicit statement like "You are running inside the Claude desktop app
   (Code tab)" — its presence or absence is a direct fact, not a guess.
   State it in one line, e.g. "Running on **PAVILION**, via the **terminal
   CLI**."
2. Read `PROGRESS-SUMMARY.md` in this folder fully — it always reflects
   *current* status, not a log.
3. Give a 2-3 sentence recap of where things stand and what's next, before
   proceeding with whatever's asked.
